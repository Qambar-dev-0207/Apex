## 🔄 The Autonomous Loop (Agentic Flow)

1.  **Ingestion**: User input is analyzed for sentiment, load, and intent.
2.  **Autonomous Trigger**: If the intent matches a **Sovereign Skill** (e.g., "Run Security Audit"), the relevant expert plan is injected instantly, bypassing the planning latency.
3.  **Multimodal Planning**: Gemini Pro creates a DAG, factoring in the active project workspace and visual context.
4.  **Parallel Compute**: The Dispatcher triggers agents in parallel, gated by the **Hardware Bridge** to ensure system stability.
5.  **Validation & Synthesis**: All outputs are verified in a sandbox and merged into a rich "Supercomputer Synthesis" response.
6.  **Evolution**: Background learning extracted from code diffs and performance logs refines the skill library for the next session.
